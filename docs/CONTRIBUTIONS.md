# Fork 的贡献范围与展示口径

本项目以 CUT / FastCUT 为基础，重点是把非配对图像转换实验接入医学影像数据和训练环境。原始 CUT、PatchNCE、FastCUT 方法与基础训练框架应归属于上游作者。

## 已有实现

- MONAI / NIfTI 数据接入：统一方向、像素间距、平面裁剪/填充和百分位归一化，构建可按 epoch 重现的非配对切片采样。
- MRI 体数据推理：逐切片生成、重建体数据、导出变换后的 affine 和像素间距，并输出预处理源图作对照。
- 实验组件：ConvNeXt / ConvNeXtV2、MONAI U-Net、多尺度判别器，以及 SSIM、边缘、elastic 和感知损失的集成与配置。
- 工程适配：Ascend 兼容入口、Accelerate 网络与优化器准备、分布式采样、动态特征 MLP 初始化、网络权重恢复和回归检查。

这些内容可作为“基于现有方法的医学影像适配与工程实现”展示。网络/损失存在代码，不等于它们在医学任务上已经证明更优。

## 需要继续整理

| 事项 | 可交付材料 |
| --- | --- |
| 真实数据实验 | 数据来源与划分、完整配置、日志、输入/输出图、可复查指标 |
| 消融对照 | CUT 配置与各项附加损失、网络变体的独立比较 |
| 复现包 | 可公开的去标识样例或合成样例、允许分享的权重、固定版本环境 |
| SB / UNSB | 条件训练、双流采样、损失实现和时间步推理的端到端验证 |
| 3D | 与体数据对应的 3D G/D、NCE 采样与体推理实现 |
| 完整断点续训 | 优化器、调度器、随机数与采样状态保存/恢复 |

网站可以直接说明现有实现和代码入口，结果展示应另附经过核验的实验材料。当前验证范围单独记在 [VALIDATION.md](VALIDATION.md)。
